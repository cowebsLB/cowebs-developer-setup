- Several official Linux products expose only direct DEB/archive downloads or interactive repository configuration, which the current safe provider schema intentionally cannot execute.
- Repository signing keys are controlled by external vendors and can rotate after the catalog digest is recorded.

## Solutions

- Selected the existing complete Go 1.26.5 extraction via the documented `COWEBS_GO_EXE` override and reran the same test unchanged; it passed.
- Kept unrepresentable provider paths explicit and unsupported instead of adding arbitrary shell, local-artifact, consent, or interactive-configuration fields.
- Calculated each repository-key digest from the live official HTTPS resource and retained fail-closed digest verification; future legitimate key rotation requires a reviewed catalog update.
