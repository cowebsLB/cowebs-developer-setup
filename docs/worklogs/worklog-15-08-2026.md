# Cross-platform Linux delivery implementation

## Summary

Implemented the seven requested Linux delivery areas as a source-preview stack: Linux configuration intents, complete Fedora classification and deterministic planning, least-privilege Ubuntu/Fedora orchestration, the public `cowebs ... dev-setup` CLI and shared application layer, immutable cross-platform artifacts and native package definitions, guarded CI/disposable validation, and current product/security/testing/deployment documentation. The released Windows v6.2 BAT/schema-v2 runtime remains unchanged.

## Why

Ubuntu package classification was complete, but Linux could only render selected operations and Fedora had no provider catalog. There was no Linux controller, public product CLI, immutable Unix bootstrap, native packaging path, or disposable validation gate. Completing these source boundaries makes the remaining work evidence-driven: live Fedora revalidation, real disposable installations, signing, and publication.

## How

Added an explicit Fedora compatibility catalog consumed by the deterministic v2-to-v3 compiler. Extended canonical plans with typed Snap-manager, Flatpak-manager/remote, and single DNF refresh operations. Implemented verified bounded repository-key downloads, digest checks, constrained atomic APT writes, real prerequisite execution, Linux privilege detection, and privilege-partitioned broker execution. Added allowlisted Linux configuration handlers and explicit manual authentication results.

Introduced `internal/application` as the shared service boundary and `cmd/cowebs` as the public CLI. Real Linux machine operations execute through one direct-argument `sudo` child; events return to the unelevated parent so user-owned journals and state remain writable. User Flatpak and configuration operations remain in the initiating process. Added immutable manifest/update verification, cross-compilation, digest-injected Unix bootstrap generation, checksums, SPDX SBOM, Winget templates, Debian/RPM definitions, CI matrices, and a fail-closed disposable validation script.
