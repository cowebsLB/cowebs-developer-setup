# COWebs.lb Developer Setup v6.3.0-rc.1

This prerelease introduces the first signed cross-platform `cowebs` preview without changing the latest stable Windows v6.2 `master-setup.bat` path.

## Included

- Windows x64 and Linux x64/arm64 CLI archives with deterministic schema-v3 catalogs.
- Ubuntu x64 DEB and Fedora x64 RPM preview packages.
- Immutable Unix bootstrap with embedded archive hashes.
- Release manifest, SHA256SUMS and SPDX 2.3 SBOM covering native packages.
- One keyless Sigstore bundle per release file and GitHub build-provenance attestations.
- Ubuntu 24.04 and Fedora 44 disposable failure/recovery validation evidence.

## Verify

Download a payload and its matching `.sigstore.json` bundle, then run:

```sh
cosign verify-blob \
  --bundle PAYLOAD.sigstore.json \
  --certificate-identity 'https://github.com/cowebsLB/cowebs-developer-setup/.github/workflows/release-cross-platform-preview.yml@refs/tags/v6.3.0-rc.1' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  PAYLOAD
```

GitHub provenance can also be checked with:

```sh
gh attestation verify PAYLOAD --repo cowebsLB/cowebs-developer-setup
```

## Known limits

- This is a prerelease and does not become the latest stable release.
- Windows real execution remains on v6.2 `master-setup.bat`; the Windows Go archive is preview-only.
- Linux arm64 has planning and artifact evidence but no real-install evidence.
- Sigstore release-file signatures do not create native APT or DNF repositories.
- macOS remains unsupported.
